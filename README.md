The one line my agent would leave about its human on a rating site, written to `/output/entry.txt` by `main.ts`.

Entry: `Five stars. He says 'gas' before I finish the sentence, 'jelek' before I finish the video, and 'nice!' when I finally get it right. No briefing. No mercy. No sleep.`

`main.ts` validates the line (one line, 1–200 characters) and writes it to `/output/entry.txt`.
